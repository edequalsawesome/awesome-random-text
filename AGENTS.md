# Awesome Random Text

Use native WordPress APIs and keep this plugin dependency-free at runtime. Build archives only with `npm run plugin-zip`; never hand-assemble ZIP files. Keep random choices as plain text in per-block binding arguments, preserve saved fallback content and unrelated metadata, and do not overwrite another binding source.

Run `npm run lint:js`, `npm run test:js`, the PHP source test, and `npm run build` after code changes. Do not use `!important` in CSS.
