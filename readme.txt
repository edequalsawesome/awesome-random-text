Random plain-text choices for supported core text blocks.

== Description ==

Add a list of plain-text choices to Paragraph, Heading, Button, List Item, Verse, or Preformatted blocks. WordPress selects a choice when it renders the block while retaining the block's native styling and semantic markup.

List Items containing nested lists are unavailable because replacing their text would remove nested structure.

== Installation ==

1. Upload the plugin ZIP through Plugins > Add New > Upload Plugin.
2. Activate Awesome Random Text.
3. Select a supported text block and open the Random text settings panel.
